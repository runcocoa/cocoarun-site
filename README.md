# cocoarun-site

The Cocoa Run website: home, privacy policy, terms of use, support, and app-ads.txt for AdMob.

The page text comes from the App Store listing drafts in ~/Documents/cocoa-run-assets/2026-09-24-app-store-listing/pages/. Change the drafts, then run `python3 build.py` to rebuild the pages. The build refuses to run if any placeholder is left, and it counts banned characters.

Fonts (Nunito, Saira Condensed) are hosted here under the SIL Open Font License (assets/fonts/OFL-*.txt), so the site loads nothing from other servers and sets no cookies.

Hosting: GitHub Pages from main. The custom domain is added once the founder has bought it.
